# Legend Keyboard
كيبورد أندرويد (Kotlin) بدون أي مكتبات خارجية.

**المميزات:** عربي/إنجليزي • قاموس واقتراحات كلمات + تصحيح تلقائي (الرجوع يلغيه ويتعلّم) • كلمات شخصية متعلَّمة •
سجل حافظة (تثبيت/حذف/لصق سريع) • لوحة تعديل (أسهم، تحديد، نسخ، قص، لصق، كلمة/بداية/نهاية) •
ضغطة مطولة للأحرف البديلة والأرقام والتشكيل • سحب على المسافة لتحريك المؤشر • مسافتين = نقطة •
إيموجي بتبويبات وآخر المستخدمة • صف أرقام اختياري • حجم مفاتيح • 4 ثيمات • هزاز • شفت ذكي.

الـ APK يتبنى تلقائياً من تبويب Actions ويُنشر في Releases (موقّع بمفتاح ثابت، فالتحديث يثبّت فوق القديم).

قاموس الكلمات مبني على FrequencyWords (hermitdave) المرخّص CC-BY-SA 4.0.
